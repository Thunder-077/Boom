# 多年级排考实施与验收记录

日期：2026-11-16。对应设计与计划均为同日的 multi-grade-exam-planning 文档。

## 已实现的使用行为

1. 成绩和教师工作簿读取全部非空 Sheet，Sheet 年级限定为高一、高二、高三（允许首尾空白）。整本校验后事务替换，后续 Sheet 出错不清空原数据。
2. 教师可监考年级取所在 Sheet。允许任教班级跨年级，同一 Sheet 同名教师合并任课信息；跨 Sheet 同名教师拒绝整次导入，并报告来源位置。
3. 高三备注去除首尾空白后为“综评班”时归入综评组，保留原始备注。同班标记冲突拒绝导入。其他年级及旧数据按普通组处理。
4. 普通组与综评组分别使用人数配置、分场及合并尾场，禁止混场。普通组不能占用“综评x场”；综评组优先使用“综评x班”生成考场，不足时使用考试教室中配置的“综评x场”，数量不足时明确失败。同名空间别名有校验，避免人数和监考数重复累加。
5. 一次生成全部有效年级，各年级独立求解。同科教师先尽量覆盖更多考场，再补同科监考席位，不足由本年级其他合格教师补位；禁排、停用和时间冲突保持硬约束。辅助岗位保留跨年级任课回避上下文。楼层流动任务按年级、楼层、重叠时间合并。
6. 同一批次下每个年级一个目录，学生资料与监考资料均按年级输出。监考生成保留学生资料原字节，考场重排清除旧监考快照及旧监考文件。
7. 数据库 migration 随应用启动执行。旧学生保留并默认普通组；旧教师来源 Sheet 无法推断，保留原数据及空归属，需重新导入教师表后才能生成新监考结果。

试用顺序：启动开发版，重新导入两本工作簿，检查各年级配置及考试时间，生成考场，再分配监考，打开批次目录检查各年级资料。
