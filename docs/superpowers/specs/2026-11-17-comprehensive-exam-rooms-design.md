# 高三综评专用考试教室设计

## 目标

高三综评组不再固定使用 14—16 场，也不再使用教学班教室，只从考试教室配置中选择名称符合“综评x场”的教室。

## 已确认规则

- “综评x场”为综评专用，普通组不能使用。
- 按 x 的阿拉伯数字顺序选择；数量不足或已被占用时明确报错。
- 其他年级及普通组的现有分配规则保持不变。

## 方案

采用名称识别方案：在现有考场选择函数中识别考试教室名称，不增加数据库字段或迁移。仅名称符合“综评”后紧跟正整数及“场”的考试教室纳入专用资源，避免把普通教室或描述性名称误判为综评场。

未采用动态读取现有 14—16 场作为默认资源的方案，因为它仍会把编号规则隐含在代码中，也不符合只能使用显式“综评x场”配置的要求。

## 影响与验收

修改考场选择及原有针对固定编号的测试，补充综评场独占、数字排序、拒绝教学班和占用后报错的覆盖。同步修正旧设计、验收说明，使文档与现行规则一致。
